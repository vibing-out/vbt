# Journey storyboard

The planned screens for a voter's and an official's path through VBT. Use the list below as the target set when building each screen. The design mockups are on the storyboard canvas, https://claude.ai/artifact/KjRXemXy7SBcEfk4TzDbFC. No mockup code is kept in this repo.

| Row | Screens |
| --- | --- |
| Voter | `Main` (receipt slip), `Scan`, `TrackCast`, `TrackNight`, `TrackCertified`, `TrackChallenged`, `TrackDiscarded`, `TrackSpoiled`, `TrackCastEs` (Spanish), `TextUpdates` (T-18 phone simulator, stretch) |
| Officials | `AdminUpload`, `AdminSelect` (with paging), `AdminConfirm`, `AdminPublished`, `AdminCounty` (county view, T-09) |
| Verifier | `VerifierPass`, `VerifierFail` (T-15 is a command-line tool; these show its terminal output) |
